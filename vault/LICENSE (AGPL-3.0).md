# LICENSE (AGPL-3.0-or-later)

DOMinic is licensed **GNU Affero General Public License v3.0 or later** (`chore: license DOMinic under AGPL-3.0-or-later`, PR-era `0fc772d`). `package.json` declares `"license": "AGPL-3.0-or-later"`.

What that means in one line: anyone may use, modify, and redistribute the code, but a modified version offered to users **over a network** must also offer them its complete source — the AGPL's network-use clause, which the plain GPL lacks. Fitting for a browser OS meant to be hosted.
